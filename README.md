

# Galería Virtual

Aplicación de escritorio en Java donde un personaje recorre una galería de arte y se acerca a los cuadros.
Se tiene por objetivo su virtualización 

## Tecnologías
- Java
- Swing / AWT
- Eventos de teclado (`KeyListener`) y animación con `ActionListener`
- `ImageIO` para cargar las imágenes

## Características
- Personaje que se mueve con el teclado
- Cuadros definidos como rectángulos en la galería
- Ventana de 1200x600
